# الأمان والحدود

## الأسرار التي لم تُضمّن

تم استبعاد ملف `.env`، وجلسة Telegram، ورقم الهاتف، وكلمة مرور 2FA، ورموز تسجيل الدخول، ورمز VNC، ورمز GitHub، وأي ملفات مؤقتة تحتوي على بيانات اعتماد. لا تُعد إنشاء هذه الملفات من نسخة ZIP أو ترفعها إلى GitHub.

## صلاحية الجلسة

جلسة Telegram تمنح وصولًا فعليًا إلى الحساب بحسب ما يسمح به Telegram. إذا تسربت، قد يستطيع حاملها قراءة المحادثات أو إرسال الرسائل أو تنزيل الوسائط. يجب حفظها بصلاحية `600`، وتدويرها أو إبطالها إذا ظهرت في سجل أو ملف عام.

## الرابط العام

رابط Quick Tunnel عام ومؤقت. كل من يملك الرابط قد يحاول إرسال طلبات إلى MCP. لذلك يجب عدم نشره، والأفضل استخدام نطاق دائم مع Cloudflare Access أو مصادقة قوية أو شبكة خاصة.

## العمليات الخارجية

أدوات القراءة مثل `tg_status` و`tg_list_dialogs` و`tg_read_messages` أقل خطورة. أما `tg_send_message` و`tg_send_file` و`tg_create_group` فتقوم بتغيير خارجي أو نشر محتوى. وأدوات `tg_delete_message` و`tg_pin_message` و`tg_add_member` محمية بمعامل تأكيد إضافي.

مع ذلك، وجود معامل التأكيد لا يغني عن مراجعة المستخدم للنص والوجهة والملف. يجب ألا يرسل Gemini رسالة أو يحذف محتوى اعتمادًا على تفسير غامض.

## ما لم نفعله

لم نفتح تنفيذ Telegram API عامًا، ولم نضف أداة لإدارة كل الصلاحيات دفعة واحدة، ولم نضع أسرار الحساب داخل هذه الحزمة، ولم نرسل أي رسالة جديدة أثناء عملية توسيع الخادم.

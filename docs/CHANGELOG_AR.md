# سجل التغييرات

## النسخة الموسعة — 14 أغسطس 2026

تم تحديث `tg_list_dialogs` لتمييز القنوات الحقيقية عن مجموعات Supergroup باستخدام خصائص Telegram `broadcast` و`megagroup`، بدل تصنيف كل كائن Telethon من نوع `Channel` كقناة.

تم رفع الحد الافتراضي للقائمة إلى 50 محادثة، وإضافة حقول `is_forum` و`is_broadcast` و`is_megagroup` إلى كل نتيجة.

أضيفت أداة `tg_get_dialog_details` لإرجاع نوع المحادثة والعنوان واسم المستخدم وحالة Forum وعدد الأعضاء عند توفره.

أضيفت أداة `tg_search_messages` للبحث النصي عالميًا أو داخل محادثة محددة، وأصبح إخراجها كائنًا يحتوي على `count` و`messages`.

أضيفت أداة `tg_account_overview` لإرجاع بيانات الحساب وأعداد المجموعات والقنوات والمستخدمين وقوائم مصنفة في استجابة واحدة، لتسهيل قراءتها من Gemini.

أضيفت أداة `tg_send_file` لرفع ملف محلي إلى محادثة مع وصف اختياري والرد على رسالة اختيارية.

أضيفت أداة `tg_create_group` لإنشاء Supergroup جديد، مع خيار إنشاء Forum من البداية.

أضيفت أداة `tg_create_forum_topic` لإنشاء موضوع داخل مجموعة Forum.

أضيفت أداة `tg_list_members` لعرض أعضاء مجموعة أو قناة حتى حد معين.

أضيفت أداة `tg_edit_message` لتعديل رسالة أرسلها الحساب المتصل.

أضيفت أداة `tg_pin_message` لتثبيت رسالة، وهي تتطلب `confirm=true`.

أضيفت أداة `tg_delete_message` لحذف رسالة، وهي تتطلب `confirm=true`.

أضيفت أداة `tg_add_member` لإضافة عضو واحد، وهي تتطلب `confirm=true`.

تم تجنب إضافة `execute_method` عام؛ لأن فتح Telegram API بالكامل أمام وكيل خارجي يرفع خطر الحذف أو التغيير غير المقصود. كما بقيت تأكيدات Gemini للعمليات الخارجية قائمة؛ لأنها حماية من جهة العميل وليست صلاحية يمكن للخادم تجاوزها.

## النشر

تم تشغيل Streamable HTTP على `127.0.0.1:8080`، وربطه عبر Cloudflare Quick Tunnel بالمسار `/mcp`. اختبارات `initialize` و`tools/list` و`tg_status` نجحت، ثم ظهر الإصدار الموسع في قائمة الأدوات.

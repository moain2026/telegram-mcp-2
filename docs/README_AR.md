# Telegram MCP — حزمة التوثيق والتحديث

هذه الحزمة توثق النسخة الموسعة من خادم **Telegram MCP** الذي جرى تشغيله على كمبيوتر Ubuntu السحابي وربطه مع Gemini عبر Streamable HTTP.

## ما الذي تحتويه الحزمة؟

تتضمن الحزمة نسخة `server.py` المحدثة، وغلاف التشغيل عبر HTTP، ودليل النشر السحابي، ودليل المزامنة مع Gemini، وسجل التغييرات، وتعليمات الأمان والاختبار. لا تتضمن الحزمة أي ملف `.env` أو جلسة Telegram أو كلمة مرور VNC أو رمز GitHub أو أي مفتاح سري.

## الأدوات المضافة

أصبحت الأدوات المصدّرة من الخادم تشمل أدوات الحالة والقائمة والقراءة والإرسال والتنزيل والحل، إضافة إلى ملخص الحساب الشامل، والبحث في الرسائل، وتفاصيل المحادثات، ورفع الملفات، وإنشاء المجموعات، وإنشاء مواضيع Forum، وعرض الأعضاء، وتعديل الرسائل، وتثبيت الرسائل، وحذف الرسائل، وإضافة عضو واحد.

تعيد `tg_list_dialogs` الآن كائنًا واضحًا يحتوي على `count` و`dialogs`، وتعطي `tg_account_overview` أعدادًا منفصلة للمجموعات والقنوات والمستخدمين وقوائم مصنفة؛ وهذا يقلل احتمال أن يفسر Gemini النتيجة كعنصر واحد أو يخلط بين القنوات وSupergroups.

العمليات الحساسة مثل التثبيت والحذف وإضافة الأعضاء تتطلب معامل `confirm=true`. لم تتم إضافة منفذ عام باسم `execute_method` حتى لا يحصل أي وكيل على قدرة غير محدودة لتنفيذ أي طلب Telegram API.

## الرابط المستخدم في الاختبار

```text
https://surface-purse-jvc-sage.trycloudflare.com/mcp
```

هذا رابط Cloudflare Quick Tunnel مؤقت، وقد يتغير إذا توقفت عملية `cloudflared` أو أعيد تشغيل الكمبيوتر السحابي. لا تعتبره رابط إنتاج دائمًا.

## بدء الاستخدام في Gemini

افتح تطبيق Telegram MCP داخل Gemini، اضغط **مزامنة / Sync / تحديث**، ثم اختبر بأمر قراءة مثل:

```text
اعرض حالة حساب Telegram
اعرض المجموعات والقنوات الموجودة
```

بعد ظهور الأدوات الجديدة يمكن طلب عمليات الإرسال أو الرفع، لكن يجب مراجعة الجهة والنص والملف قبل تنفيذ أي إجراء خارجي.

## ملاحظات مهمة

ظهور مجموعات Telegram الكبيرة في Telethon يكون من نوع `Channel` تقنيًا، لذلك تم تحديث التصنيف ليستخدم `broadcast` و`megagroup`: القناة الحقيقية تظهر `channel`، والـ Supergroup يظهر `group`.

للتشغيل الدائم الآمن استخدم نطاقًا خاصًا مع شهادة TLS ومصادقة مثل Cloudflare Access أو شبكة خاصة. لا تستخدم Quick Tunnel المؤقت لخدمة إنتاجية أو لمشاركة عامة.

# telegram-mcp-2

Public sanitized release of the expanded Telegram MCP server.

The `src/` directory contains the MCP server and HTTP wrapper. The `docs/` directory contains Arabic deployment, change log, security, and Gemini synchronization documentation.

No `.env`, Telegram session, phone number, API hash, VNC password, GitHub token, or login code is included.

Read `docs/README_AR.md` and `docs/SECURITY_AR.md` before deploying.
